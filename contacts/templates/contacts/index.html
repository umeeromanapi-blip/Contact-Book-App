Contact Book REST API

Full programmatic JSON access for external clients

GET /api/contacts/

List contacts with optional query params: ?q=..., ?category=..., ?favorites=1

POST /api/contacts/

Create new contact with JSON payload: {"name": "...", "phone": "...", "email": "...", "category": "work"}

GET /api/contacts/<id>/

Retrieve single contact entity by ID.

PUT / PATCH /api/contacts/<id>/

Update contact fields with JSON payload.

DELETE /api/contacts/<id>/

Permanently remove contact by ID.

GET /api/contacts/stats/

Get aggregated stats (totals, favorites, category breakdown).
